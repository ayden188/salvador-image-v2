📸 Galerie Salvador
Un site simple et rapide pour exposer des photos avec un système de zoom (modale).

✨ Ce que fait le projet
Grille d'images : Affichage propre et organisé.

Zoom interactif : Clique sur une image pour l'agrandir.

Confort de lecture : Le scroll se bloque quand une photo est ouverte pour ne pas perdre sa place.

Navigation clavier : On peut fermer avec la touche Échap.

🛠️ Outils utilisés
HTML pour la structure.

CSS pour le design sombre et la grille.

JavaScript pour rendre le tout vivant.
